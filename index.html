Prompt a PROCESSUS. Watch it draw.

A creative-coding atelier: a notebook of steps where each cell pairs a natural-language prompt with the code a model writes for it — rendered live in a sandboxed preview.

Download for macOS View on GitHub →

Made for teaching creative coding.

Students read a prompt, see the code it produces, tweak, regenerate — and watch the sketch evolve one step at a time.

Prompt-driven steps

Each cell is a written intention. The model generates the code; the preview runs it instantly. Edit the prompt, regenerate the code.

Editable code

The generated code isn't locked: students can read it, edit it directly in the cell, and rerun — or regenerate from the prompt.

Live preview

Cells replay in order inside a sandboxed page. No build step, no tooling — the result appears as soon as the code does.

Local-first AI

Works fully offline with LM Studio. Prefer the cloud? Switch to a free Google, Groq, Mistral or OpenRouter key in one click.

How it works.

2

3

Set it up in two minutes.

PROCE55US needs a language model. Pick local — private and free — or a cloud key.

Local — LM Studio

recommended
  1. Download LM Studio — free, for any Mac.
  2. In its 🔍 Search tab, pick a coding model — Qwen2.5-Coder-7B is a good start — and click Download.
  3. Open the Developer tab and press Start Server (port 1234).
  4. That's it — PROCE55US uses LM Studio by default.

Cloud — your API key

free tiers
  1. Get a free API key from Google AI Studio, Groq, Mistral or OpenRouter.
  2. In PROCE55US, click the ⚙ gear in the toolbar.
  3. Choose the provider, paste the key — done.
