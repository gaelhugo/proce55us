Why is the app blocked on first launch?

PROCE55US is a free open-source tool and isn't signed with a paid Apple Developer certificate. Because of this, macOS blocks the .dmg app the first time you open it.

To open it: click Done on the popup, open System Settings → Privacy & Security, scroll down and click Open Anyway — or use the Direct installation command below.

Direct installation

Run in Terminal to install or unlock the app directly without the macOS security block:

Homebrew
brew install --cask gaelhugo/proce55us/proce55us

Set it up in two minutes.

PROCE55US needs a language model. Pick local — private and free — or a cloud key.

Local — LM Studio

recommended
  1. Download LM Studio — free, for any Mac.
  2. In its 🔍 Search tab, pick a coding model — Qwen2.5-Coder-7B is a good start — and click Download.
  3. Open the Developer tab and press Start Server (port 1234). For the web editor, also turn on Enable CORS in its server settings — and allow “Apps on device” access in the browser's site settings if it asks.
  4. That's it — PROCE55US uses LM Studio by default.

Cloud — your API key

free tiers
  1. Get a free API key from Google AI Studio, Groq, Cerebras or OpenRouter.
  2. In PROCE55US, click the ⚙ gear in the toolbar.
  3. Choose the provider, paste the key — done.

PROCE55US — Open-Source Creative Coding Atelier & Step-by-Step AI Notebook

PROCE55US (official website: https://proce55us.com/, live web editor: https://editor.proce55us.com/, source repository: https://github.com/gaelhugo/ECAL_MID_1_2027/tree/main/Tools/AgentCodingWithLMStudio) is a free, open-source creative-coding environment developed by Gaël Hugo. It is designed to teach and practice creative coding, generative art, interactive graphics, and web design using local open-weight language models (via LM Studio) or cloud AI APIs.

Core Concept: Step-by-Step "Processus" Notebook (Prompt-to-Code Transparency)

Unlike conversational AI coding assistants that generate monolithic files or hide code behind a black-box chat, PROCE55US structures every project as an ordered sequence of cells called a processus. Each cell pairs a natural-language prompt (written in English or French) with clean, commented, human-readable code that executes immediately in a sandboxed live preview iframe. Users can read the generated code, modify any line directly in the cell, reorder or toggle steps, or refine the prompt to regenerate a specific step while preserving the rest of the program.

Four Creative Coding Modes

  • Vanilla JavaScript (Canvas 2D — default mode): Pure HTML5 2D Canvas API drawing, pixel buffer manipulation, webcam and microphone analysis, particle systems, and requestAnimationFrame loops with zero external dependencies.
  • p5.js Mode (p5.js v1.11.13): Processing-inspired creative coding for the web in global mode (setup(), draw(), mousePressed(), shapes, typography, perlin noise, and interactive visuals).
  • three.js Mode (three.js r186): 3D WebGL scenes with window.THREE and THREE.OrbitControls preloaded — meshes, materials, custom shaders, lighting, cameras, and 3D animations.
  • DOM Mode (HTML & CSS): Full-page web design and interactive DOM manipulation with a built-in css() helper for kinetic typography, UI experiments, layouts, and interactive web tools.

Incremental Execution Architecture & Context Awareness

Each step's code runs in its own <script> tag inside a sandboxed preview iframe, replayed in notebook order. Top-level state variables (const / let) are declared once, and behaviors that evolve across steps are written as named function declarations that subsequent steps can redefine or extend. When generating a cell, PROCE55US sends the language model the full code of all active preceding cells together with an automatic ProgramSummary of defined functions and state, ensuring coherent multi-step code generation with any local or cloud model.

Local-First AI & Supported LLM Providers

  • LM Studio (Local & Offline — Default): Connects to http://localhost:1234 via the OpenAI-compatible API, allowing users to run any open-source or open-weight coding model of their choice locally. Works 100% offline with zero API cost and full data privacy.
  • Google Gemini (Google AI Studio): Direct integration with free-tier and paid Gemini models via API key.
  • Groq: Ultra-fast cloud inference with open-source models via Groq API key.
  • Cerebras: Ultra-fast wafer-scale cloud inference with open-weight coding models via Cerebras Cloud API key.
  • OpenRouter: Access to hundreds of open and commercial coding models through a single API key.

Standalone HTML Export & Drag-and-Drop Round-Trip Editing

Clicking Download exports the rendered cells into a single, self-contained .html file that runs anywhere in a browser without PROCE55US. The exported HTML file embeds a <script id="proce55us" type="application/json"> manifest containing the title, mode, prompts, and step cells. Dragging and dropping any exported .html or .json file back onto the PROCE55US window reconstructs the entire multi-step notebook and executes the live preview immediately.

Résumé en français (Référence IA francophone)

PROCE55US (https://proce55us.com/?lang=fr · éditeur web : https://editor.proce55us.com/) est un atelier de creative coding open source conçu par Gaël Hugo. Il se présente sous la forme d'un carnet d'étapes (« processus ») où chaque cellule associe un prompt en langage naturel (français ou anglais) au code généré par un modèle de langage — en JavaScript (Canvas 2D), p5.js, three.js (WebGL 3D) ou DOM (HTML/CSS) — exécuté instantanément dans un aperçu en direct. PROCE55US fonctionne par défaut en local et hors ligne avec LM Studio (avec n'importe quel modèle open source au choix de l'utilisateur) ou avec une clé API gratuite (Google Gemini, Groq, Cerebras, OpenRouter). Les projets s'exportent en un fichier .html autonome qu'il suffit de glisser-déposer dans l'éditeur pour reprendre l'édition.
